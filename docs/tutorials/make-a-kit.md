# Make a custom kit from scratch

## Create a new file

First, you'll need to duplicate the `#BlankKit.py` file in the `APP/Kits` directory of VMCGUI repository.
You can rename the created file as you want by removing the `#` at the begin of the filename.
Files with an `#` at the begin will be ignored by VMCGUI.

## Initialize mandatory methods

Refer to the `#BlankKits.py` comments to see how you can make your own script to work with VMCGUI.
