# API reference

VMCGUI is a Graphical User Interface that can be consider at two different levels :

- The **Kits** files that are supposed to be customized by users
- The **VMCGUI** core file of the application that shouldn't be modified by users

The API reference provided here dissociate those two levels. The [Kits script](kits.md) section refer to custom files located at the `APP/Kits` folder (e.g. `Debug GUI.py`), while the [GUI script](vmcgui.md) section refer directly to the `VMCGUI.py` file located in the `APP/` folder.
