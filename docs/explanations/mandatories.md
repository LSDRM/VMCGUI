# Mandatory attributes and methods

All kit files (e.g. `Debug GUI.py`) located at the `APP/Kits` folder of the VMCGUI repository, share mandatory attributes and methods that are expected by the VMCGUI core program (located in the `APP/VMCGUI.py` file).

Everything is specified in the [`#BlankKit.py` template](https://github.com/LSDRM/VMCGUI/blob/main/APP/Kits/%23BlankKit.py) with comments.
